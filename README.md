# Tableau-Projecct
Overview

This project focuses on analyzing Superstore sales data using Power BI to uncover insights into sales performance, profitability, customer demand, and regional trends.

The dashboard provides an interactive and visual representation of key business metrics to support data-driven decision-making.

Dashboard Features
Revenue, Profit, and Quantity KPIs
Monthly and Yearly Sales Trends
Top 5 Selling Products
Sales by Region Analysis
Category Sales and Profit Comparison
Profit Margin Visualization
Discount Impact on Sales
Top Demand by Sub-Category
Tools & Technologies
Power BI
DAX
Power Query
Data Visualization

Key Insights
Identified top-performing regions by sales
Analyzed category-level profitability
Tracked monthly and yearly sales growth
Evaluated the impact of discounts on profits
Highlighted high-demand products and sub-categories
